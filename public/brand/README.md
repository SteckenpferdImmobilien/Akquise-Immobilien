# Steckenpferd-Markenbilder

Der Nutzer hat das Steckenpferd-Immobilien-Logo als Bildvorlage bereitgestellt. Die PNG-Dateien sind daraus mit Bildgenerierung abgeleitete Webfassungen: Logo mit Wortmarke und separates Pferdesymbol für das App-Icon. Sie sind keine unveränderten Originaldateien des Uploads. Eine spätere Originaldatei kann diese Dateien ersetzen.

Die Dateien werden lokal mit der App ausgeliefert und für den Offline-Modus vorgehalten. Keine externe Bildabfrage, keine Änderungen am Objektspeicher oder an persönlichen Fotos.
